# 每日营养素需求表

## 成人推荐量
| 营养素     | 每日推荐量          | 来源                 |
|------------|---------------------|----------------------|
| 蛋白质     | 0.8-1.2g/kg体重     | 鸡蛋、牛奶、豆类     |
| 脂肪       | 20-30%总热量        | 橄榄油、坚果         |
| 碳水       | 45-65%总热量        | 全谷物、蔬菜         |
| 膳食纤维   | 25-30g              | 蔬菜、水果、粗粮     |
| 钙         | 800-1000mg          | 牛奶、豆腐、深绿叶菜 |
| 铁         | 8-18mg（男女差异）  | 红肉、动物肝脏、菠菜 |

## 特殊需求
- **孕妇**：叶酸400μg/天，增加铁和钙摄入。
- **老年人**：增加蛋白质（1.0-1.2g/kg体重），补充维生素D。
