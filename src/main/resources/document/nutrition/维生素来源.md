# 维生素来源清单

## 常见维生素及食物
| 维生素 | 主要来源                  | 功能                   |
|--------|---------------------------|------------------------|
| A      | 胡萝卜、菠菜、动物肝脏    | 护眼、增强免疫力       |
| B族    | 全谷物、瘦肉、鸡蛋        | 代谢调节、神经系统健康 |
| C      | 橙子、猕猴桃、青椒        | 抗氧化、促进铁吸收     |
| D      | 阳光、三文鱼、蛋黄        | 钙吸收、骨骼健康       |
| E      | 坚果、植物油              | 抗氧化、保护细胞       |

## 补充建议
- **均衡饮食**：天然食物优先，避免过量补充剂。
- **特殊人群**：孕妇需补叶酸（B9），老年人需补维生素D。
