# 热量摄入推荐表

## 计算公式
**每日所需热量 = BMR × 活动系数**
- **BMR公式**：
    - 男性：10×体重(kg) + 6.25×身高(cm) - 5×年龄 + 5
    - 女性：10×体重(kg) + 6.25×身高(cm) - 5×年龄 - 161
- **活动系数**：
    - 久坐（办公室）：1.2
    - 中等活动（每周3次运动）：1.55
    - 高强度活动（每天运动）：1.9

## 示例
- **男性**：体重70kg，身高175cm，年龄30岁，久坐
    - BMR = 10×70 + 6.25×175 - 5×30 + 5 = 1731kcal
    - 每日热量 = 1731 × 1.2 = **2077kcal**

## 应用场景
- **减脂**：每日热量减少300-500kcal（不可低于1200kcal）。
- **增肌**：每日增加200-300kcal，结合力量训练。
