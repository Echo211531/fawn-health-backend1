# BMI计算指南

## 计算公式
BMI = 体重（kg） ÷ 身高²（m²）

## 分类标准
| BMI范围   | 分类       | 健康建议                 |
|-----------|------------|--------------------------|
| <18.5     | 体重过轻   | 增加营养摄入             |
| 18.5-23.9 | 正常范围   | 保持健康生活方式         |
| 24-27.9   | 超重       | 控制饮食、增加运动       |
| ≥28       | 肥胖       | 就医评估代谢风险         |

## 注意事项
- **局限性**：BMI无法区分肌肉与脂肪比例（运动员可能误判）。
- **儿童/老年人**：需结合体脂率、腰围等综合评估。
