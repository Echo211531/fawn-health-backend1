# 饮食计划模板

## 减脂餐（1200-1500kcal/天）
**早餐**：水煮蛋2个 + 燕麦片40g + 西蓝花100g  
**午餐**：糙米饭100g + 鸡胸肉150g + 清炒菠菜200g  
**晚餐**：蒸鱼150g + 番茄豆腐汤 + 紫薯100g  
**加餐**：无糖酸奶100ml + 一小把坚果

## 增肌餐（2500-3000kcal/天）
**早餐**：全麦面包2片 + 牛奶250ml + 鸡蛋3个  
**午餐**：米饭150g + 牛肉200g + 烤西兰花200g  
**晚餐**：意大利面150g + 鸡腿200g + 沙拉300g  
**加餐**：蛋白粉30g + 香蕉1根

## 注意事项
- **蛋白质摄入**：每餐分配20-30g蛋白质，提高合成效率。
- **烹饪方式**：蒸、煮、烤为主，避免油炸。
